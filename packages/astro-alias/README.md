# `@cloudflare/polystella-astro`

Compatibility package for the PolyStella Astro integration. It forwards every public API to [`@cloudflare/polystella`](https://www.npmjs.com/package/@cloudflare/polystella).

```sh
pnpm add @cloudflare/polystella-astro
```

```ts
import polystella from "@cloudflare/polystella-astro";
```
