The admin UI is easier to scan and more honest about what happened.

- **Catalog:** opening the page no longer turns runtime overrides on or off; only **Apply overrides** changes them. Narrow columns get stacked rows and a group select instead of a wide table. Override text boxes stay closed until edited, the action bar stays in view with an unsaved count and **Discard**, and **Synced**, **Not deployed** and **Unsaved** badges mark each key. Search filters keys inside a group, the 100-key limit is shown, and a save conflict offers **Reload catalog**.
- **Batch translation:** a browser run says whether it finished, failed, or was stopped, with its counts, and **Translate the … left** continues after a stop. Browser runs are limited to 5,000 translations like server jobs, and show results 100 at a time. A server job's **Failures** tab lists every failed row with its entry title and an edit link; `batch/results` accepts an optional `outcome` filter for this. **Load more** no longer loads the same rows twice, and dead ends (no locales, no search matches, nothing to do, a failed load) explain themselves. **Run settings** check **Max output tokens** as you type and keep the run or **Retry** button off until it's valid, instead of failing every translation. Their default reads **Same as Translation settings**, a failed load offers **Retry**, summaries use short model names and formatted numbers, and a retry job says **Retry of** the job it came from.
- **Content editor:** when PolyStella can't check an AI-translated entry for edits, it says **Couldn't check for edits** instead of showing it as unchanged, and offers **Keep AI flag** and **Remove AI flag**. **Edited since AI translation** is now **Edited after AI translation**. Fields are one labelled group with a count, the button names what it does, and failures are listed per locale.
- **Settings:** **Saved** and errors show next to **Save**. Closed locale cards show a custom glossary or thinking choice. **Max output tokens** checks its 256–131,072 range as you type. The two long switch labels are now **Remove AI flag on edit** and **Translate SEO on published entries**. Turning a collection off and on keeps its fields, and one collection failing to load no longer hides the whole tab. The code-defaults page warns before leaving with unsaved text.
- **Sandbox:** **Copy** button, short model names, and a clear message when no locale or model is set up.
- Errors and progress are announced to screen readers, ⓘ buttons have a larger tap area, and the debug view uses a label list and tabs instead of nested disclosures.
