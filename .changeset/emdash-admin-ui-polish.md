The admin UI is easier to scan and more honest about what happened.

- **Catalog:** opening the page no longer turns runtime overrides on or off; only **Apply overrides** changes them, and its ⓘ says what off and on mean. While it's off, saved overrides are faded and marked **Not applied**. The **Deployed** column is now **Current translation**. Narrow columns get stacked rows and a group select instead of a wide table. Override text boxes stay closed until edited, the action bar is a card under the locale picker, with an unsaved count and **Discard**, and **Synced**, **Missing** and **Unsaved** badges mark each key. Search filters keys inside a group, the 100-key limit is shown, and a save conflict offers **Reload catalog**.
- **Batch translation:** a browser run ends with a green, amber or grey banner that says whether it finished, failed, or was stopped, with its counts, under a short summary of the run's settings, and **Translate the … left** continues after a stop. Browser runs are limited to 5,000 translations like server jobs, and show results 100 at a time. A server job's **Failures** tab lists every failed row with its entry title and an edit link; `batch/results` accepts an optional `outcome` filter for this. **Load more** no longer loads the same rows twice, and dead ends (no locales, no search matches, nothing to do, a failed load) explain themselves. **Run settings** check **Max output tokens** as you type and keep the run or **Retry** button off until it's valid, instead of failing every translation. While closed they show a badge for each change, with **Reset**. Their default reads **Same as translation settings**, **Extra instructions** is now **Additional instructions**, a failed load offers **Retry**, summaries use short model names and formatted numbers, and a retry job says **Retry of** the job it came from. **Retry...** is now **Retry**, its redo switch says what it overwrites, and server job cards have more room. A run of selected entries that would only skip existing translations can't start.
- **Content editor:** fields are small toggle chips with **Select all** and **Clear all**, and the button names what it does; its ⓘ says which entry it translates from. The **AI-translated** badge shows the date and model on hover or click, with **Remove flag** beside it. After a run, one note asks you to review before saving. Untranslated block types get a short warning that names them; the `translate-content` response adds `unlistedBlockTypes` for this, and its `notice` no longer repeats them. When PolyStella can't check an AI-translated entry for edits, it says **Couldn't check for edits** instead of showing it as unchanged. **Edited since AI translation** is now **Edited after AI translation**, and failures are listed per locale. When creating drafts, the progress bar stays up with the created drafts under it.
- **Progress:** the sandbox, catalog generation and the content editor show a step list over a slim bar, and the button shows it's busy.
- **Settings:** **Saved** and errors show next to **Save**. Each language card shows one **Default** or **Custom** badge; hover it for the model, thinking and glossary it uses or what it changed. **Default model** shows **From code** while nothing is picked in settings, and model names are shortened. **Max output tokens** checks its 256–131,072 range as you type. The two long switch labels are now **Remove AI flag on edit** and **Translate SEO on published entries**. Clicking a tab no longer shows a focus ring; keyboard focus still does.
- **Collections:** **Enabled** collections are rows with their fields as chips, and **Edit** opens **Fields to translate** as toggle chips with **Select all** and **Clear all**. A repeater's chip shows how many subfields are picked and opens them in a popover. The rest sit in a short **Disabled** list. Turning a collection off and on keeps its fields, and one collection failing to load no longer hides the whole tab.
- **Code-defined glossary:** **Overview** and **Raw** tabs. Raw shows the glossary file as written, and **Copy** copies it. `loadGlossaryDefaults` keeps each file's text in a new optional `source` field (type `GlossaryDefault`); it is never sent to the model. Inline glossaries are shown as JSON. `settings/translation` now returns `defaultGlossary` as an object instead of a JSON string, and returns the file text as `defaultGlossarySource` when a `glossarySource` query names one locale. The code-defaults page warns before leaving with unsaved text.
- **Sandbox:** optional **Additional instructions** for one test (up to 2,000 characters, never saved; `translation-sandbox` accepts `instructions`), the time a translation took, the output's character count, **Copy**, short model names, and a clear message when no locale or model is set up.
- New-tab links are blue. Errors and progress are announced to screen readers, ⓘ buttons have a larger tap area, and the debug view uses a label list and tabs instead of nested disclosures.
