The admin shows token usage and a list-price cost estimate in tooltips: on the sandbox's translation time, the content editor's "Translated into the form" note and drafts-created count, the catalog's completion status, a browser batch run's end counts, a server job's progress count, and each debug attempt. `translate-content`, `catalog/generate` and `translation-sandbox` responses, server job views and batch result rows gain an optional `usage` field.
